# Taiwan NHI 降血脂藥物給付新制（2026/9/1）臨床實務完整手冊
### 新舊制度比較、風險分層、完整藥品給付對照表與臨床決策指引

**依據**：健保審字第1150671962號，修訂全民健康保險醫療辦法「全民健康保險藥物給付項目及支付標準」2.6.1（降血脂藥物給付規定表）、2.6.2（Ezetimibe單方）、2.6.3（Ezetimibe/statin複方）條文，**115/9/1（西元2026/9/1）生效**。

**使用對象**：心臟科、內分泌科、腎臟科、一般內科門診醫師；藥師；健保申報/核刪審查人員。

---

## 1. 摘要

自2026年9月1日起，健保降血脂藥物給付制度由「單一張以疾病診斷/危險因子計數為觸發條件的給付規定表」，改為「**表一：以ASCVD風險分級為核心的目標導向（goal-directed）LDL-C治療表**」為主體，並將「**表二：原給付規定**」保留給特定藥品項目繼續適用。這是一次**制度邏輯的根本轉變**——從「病人有沒有這個診斷/幾個危險因子」的靜態資格審查，轉為「病人屬於哪個ASCVD風險等級 → 對應的LDL-C起始治療門檻與治療目標值 → 依既定時程（6-8週/1-3個月/6個月，或3-6個月/6-12個月）追蹤達標與否、逐步調整治療」的動態治療流程。

**對臨床開藥最重要的一句話提醒：新制表一「不是」以成分（ingredient）或藥品名稱認定，而是逐一以健保代碼（醫令代碼）認定——同一成分、同一品牌、甚至同一藥品不同劑量，都可能分屬「擴增（表一新制）」與「維持原給付規定（表二舊制）」兩份不同清單。開立處方前務必查核實際調劑品項的健保代碼，不能用成分或印象判斷。**

本次異動全國共187項降血脂相關品項受影響，其中57項「擴增」納入表一新制、130項「維持原給付規定」仍依表二舊制。**Tonvasca（同抑脂膠囊，pitavastatin 2mg/ezetimibe 10mg，健保代碼AC61165100）是擴增名單中的一員，適用新制表一**；但其姊妹複方產品LIVAZEBE HD（力沛加複方錠，pitavastatin 4mg/ezetimibe 10mg，健保代碼BC28884100）則維持舊制，兩者不可互相推論。

**極高／非常高風險 處方規定原文（逐字，附件2）：**

> 一、起始治療：依據基線血脂值、用藥史和臨床狀況，給予中至高強度statin或合併ezetimibe。
> 二、經起始治療6~8週後，檢測血脂指標，如治療達標，則維持治療，並應每6個月追蹤血脂指標；如血脂值未達標，檢視服藥狀況，並考慮調整至高強度statin或最大耐受statin劑量，同時考慮合併non-statin治療，包含：ezetimibe、PCSK9單株抗體、siRNA、ATP citrate lyase抑制劑。
> 三、更動治療1~3個月內需追蹤血脂值是否達標，如治療達標，則維持治療，並應每6個月追蹤血脂指標；如血脂值未達標，檢視服藥狀況，並考慮調整藥物組合。

**高風險 處方規定原文：**

> 一、起始治療：依據基線血脂值與臨床狀況，給予中至高強度statin或合併ezetimibe；同時進行生活型態改變。
> 二、經起始治療6~8週後，檢測血脂指標，如治療達標，則維持治療，並應每6個月追蹤血脂指標；如血脂值未達標，檢視服藥狀況，並考慮使用高強度statin或最大耐受statin劑量或同時合併non-statin治療，包含：ezetimibe、PCSK9單株抗體、siRNA、ATP citrate lyase抑制劑。
> 三、更動治療1~3個月內需追蹤血脂值是否達標，如治療達標，則維持治療，並應每6個月追蹤血脂指標；如血脂值未達標，檢視服藥狀況，並考慮調整藥物組合。

**中、低風險 處方規定原文：**

> 一、起始治療：進行生活型態改變，並處置心血管風險因子。
> 二、經起始治療3~6個月後，檢測血脂指標，如治療達標，則維持治療，並應每6-12個月追蹤血脂指標；如血脂值未達標，給予中強度statin。
> 三、中強度statin治療6~8週後追蹤血脂值是否達標，如治療達標，則維持治療，並應每6-12個月追蹤血脂指標；如血脂值未達標，檢視服藥狀況，並可給予高強度statin或最大耐受statin劑量或合併non-statin治療。

## 3. 風險分層完整定義（判斷流程）

### 3.1 極高風險（Extreme Risk）—— 目標 LDL-C < 55 mg/dL（non-HDL-C < 85）

符合以下任一大類即屬極高風險：

**(一) 冠狀動脈疾病 合併 下列任一臨床狀況：**
1. 一年內曾經歷心肌梗塞
2. ≥兩次心肌梗塞病史
3. 多支冠狀動脈阻塞
4. 急性冠心症合併糖尿病
5. 周邊動脈疾病或頸動脈狹窄

**(二) 周邊動脈疾病 合併 下列任一臨床狀況：**
1. 冠狀動脈疾病
2. 頸動脈狹窄

### 3.2 非常高風險（Very High Risk）—— 目標 LDL-C < 70 mg/dL（non-HDL-C < 100）

**(一) 經臨床檢查確診為動脈硬化心血管疾病，包含：**
1. 急性冠心症病史
2. 接受血管再通術（心導管介入治療或外科冠狀動脈繞道手術）
3. 缺血性中風／短暫性腦缺血發作合併動脈硬化相關疾病或病史
4. 周邊動脈疾病（曾接受血管再通術、有肢體缺血相關症狀或截肢）

**(二) 經影像檢查確認有顯著斑塊負擔，定義為≥50%直徑狹窄率，包含：**
1. 冠狀動脈血管攝影
2. 冠狀動脈或周邊血管電腦斷層攝影
3. 頸動脈或周邊血管超音波

### 3.3 高風險（High Risk）—— 目標 LDL-C < 100 mg/dL（non-HDL-C < 130）

符合以下任一項：
1. 糖尿病
2. 慢性腎臟病（進入透析治療前的慢性腎臟病，包括 **UACR ≥ 30 mg/g** 或 **eGFR < 60 mL/min/1.73m²** 至少持續3個月）
3. LDL-C ≥ 190 mg/dL
4. 冠狀動脈鈣化分數（CAC）≥ 400

> 註：當ASCVD風險分級為高風險，且合併嚴重高膽固醇血症、肌腱黃色瘤、早發心血管疾病或家族病史時，應依照**台灣家族性高膽固醇血症診斷標準**進行家族性膽固醇血症篩檢（見§3.6）。

### 3.4 中風險（Moderate Risk）—— 目標 LDL-C < 115 mg/dL（non-HDL-C < 145）

**2項（含）以上心血管風險因子**（因子定義見§3.6）。

### 3.5 低風險（Low Risk）—— 目標 LDL-C < 130 mg/dL（non-HDL-C < 160）

**1項心血管風險因子**。

*（0項風險因子：目標 LDL-C < 160 mg/dL，無次要non-HDL-C目標值。）*

### 3.6 心血管風險因子定義（用於中/低風險分層計數，共6大類）

1. 高血壓
2. 男性 ≥ 45歲，女性 ≥ 55歲
3. 早發性冠心病家族史（男性 ≦ 55歲，女性 ≦ 65歲）
4. HDL-C：男性 < 40 mg/dL，女性 < 50 mg/dL
5. 抽菸
6. 代謝性症候群（符合以下**至少三項**）：
   (一) 腹部肥胖（男性 ≧ 90cm，女性 ≧ 80cm）
   (二) 血壓偏高（≧130/85mmHg 或使用高血壓藥物）
   (三) 空腹血糖偏高（≧100mg/dL 或使用糖尿病藥物）
   (四) 空腹TG偏高（≧150mg/dL 或使用治療TG血脂藥物）
   (五) HDL-C偏低（男性<40mg/dL，女性<50mg/dL）

### 3.7 各風險等級評估建議

**極高風險、非常高風險：**
- 初始評估應檢測完整血脂指標，並應於**急性病人入院後24小時內**完成血脂檢驗
- 處置各項可改善心血管風險因子，包含：血壓、HbA1c、肥胖、抽菸、酒精攝取、生活型態

**高風險、中風險、低風險：**
- 給予完整血脂指標檢測，辨識各項可改善心血管風險因子（血壓、HbA1c、肥胖、抽菸、酒精攝取、生活型態）
- ASCVD風險分級為高風險，當有嚴重高膽固醇血症、肌腱黃色瘤、早發心血管疾病或家族病史時，應依照台灣家族性高膽固醇血症診斷標準進行家族性膽固醇血症篩檢
- 若未符合上述高風險條件，應以列在低至中風險欄位的心血管風險因子數量作為風險評估

**non-HDL-C的使用時機：** 當LDL-C達到理想治療目標後，non-HDL-C（＝總膽固醇－HDL-C）可作為血脂治療次要標的，尤其適用於合併有高三酸甘油脂、糖尿病、或肥胖的病人，以做進一步的心血管風險評估。

### 3.8 風險分層判斷流程（文字流程圖）

```
Step 1：病人是否有冠心病/周邊動脈疾病合併§3.1所列高危合併症？
  → 是 → 【極高風險】LDL-C目標 <55（non-HDL<85）
  → 否，繼續 Step 2

Step 2：病人是否有確診ASCVD（急性冠心症/血管再通術後/缺血性中風合併動脈硬化/
        周邊動脈疾病）或影像確認≥50%狹窄？
  → 是 → 【非常高風險】LDL-C目標 <70（non-HDL<100）
  → 否，繼續 Step 3

Step 3：病人是否有下列任一：糖尿病 / CKD(UACR≥30 or eGFR<60,≥3個月)
        / LDL-C≥190 / CAC≥400？
  → 是 → 【高風險】LDL-C目標 <100（non-HDL<130）
         → 同時檢查：是否有嚴重高膽固醇血症/肌腱黃色瘤/早發心血管疾病
            家族史 → 是 → 加做家族性高膽固醇血症篩檢
  → 否，繼續 Step 4

Step 4：計算§3.6心血管風險因子個數（高血壓、年齡、早發冠心病家族史、
        低HDL-C、抽菸、代謝症候群，共6類）
  → ≥2項 → 【中風險】LDL-C目標 <115（non-HDL<145）
  → 1項   → 【低風險】LDL-C目標 <130（non-HDL<160）
  → 0項   → 【0項風險因子】LDL-C目標 <160
```

## 6. 詳細臨床實務建議

### 6.1 依科別/情境建議

#### （一）心臟科（急性冠心症、慢性穩定冠心病、周邊動脈疾病）

- **急性冠心症（ACS）病人入院時**：依§3.7規定，應於**入院後24小時內**完成完整血脂檢驗，並依§3.1極高風險判斷準則（一年內MI、≥2次MI病史、多支冠狀動脈阻塞、ACS合併糖尿病、周邊動脈疾病或頸動脈狹窄）或§3.2非常高風險準則（急性冠心症病史即符合）評估風險分級。
- ACS病人絕大多數落入**極高風險或非常高風險**分級，目標LDL-C分別為<55或<70 mg/dL，起始治療即應「給予中至高強度statin或合併ezetimibe」——即高強度statin+ezetimibe起始合併治療，在新制文字上已是明列的起始治療選項之一，而非僅statin治療失敗後才加用，這點與過去「先單方、再視情況加用」的實務流程有觀念上的差異，值得心臟科團隊特別留意。
- 6-8週後追蹤：若未達標，除調整statin強度/劑量外，條文明列可**合併non-statin治療，包含ezetimibe、PCSK9單株抗體、siRNA、ATP citrate lyase抑制劑**——為PCSK9單株抗體與siRNA類藥物（如inclisiran）在極高/非常高風險病人上的加用，提供了明確的表一架構位置。
- 慢性穩定CAD病人：依§3.2非常高風險（多數穩定CAD病人符合「經臨床檢查確診為動脈硬化心血管疾病」），目標<70 mg/dL，追蹤節奏比照極高/非常高風險流程。

#### （二）內分泌科（糖尿病）

- 糖尿病病人**依§3.3自動落入至少「高風險」**分級（目標LDL-C<100 mg/dL），若同時合併ASCVD確診或急性冠心症合併糖尿病等§3.1/§3.2條件，則進一步提升至非常高風險或極高風險（目標<70或<55 mg/dL）——**「糖尿病」本身不再是單一固定的給付門檻依據，而是進入風險分層演算法的其中一個輸入變項**，需與是否合併確診ASCVD、CKD、LDL-C基礎值、CAC分數等因子綜合判斷實際分級。
- 糖尿病病人起始治療即可考慮中至高強度statin合併ezetimibe（若屬高風險以上），且6-8週追蹤未達標時可及早合併non-statin治療；門診糖尿病照護排程若已固定3-6個月複診，建議另外安排6-8週的血脂追蹤時間點，勿與糖尿病常規回診週期混淆導致血脂達標評估延遲。
- 糖尿病合併HbA1c控制不佳、代謝症候群病人，屬於§3.6風險因子計算中的「代謝性症候群」項下之一環（空腹血糖偏高≧100mg/dL或使用糖尿病藥物即計入），若未達§3.3高風險的糖尿病定義門檻（如糖尿病前期），仍可能因代謝症候群相關因子累加而落入中/低風險分層，須逐項核算。

#### （三）腎臟科（CKD）

- CKD病人是否落入§3.3高風險，取決於明確的檢驗數字門檻：**UACR≥30mg/g 或 eGFR<60mL/min/1.73m² 至少持續3個月**（進入透析前）。腎臟科門診排程若定期追蹤UACR/eGFR，建議同步將此兩項數字是否達門檻、是否已持續滿3個月，納入血脂風險分層之判斷依據並留存於病歷。
- 若CKD病人同時合併確診ASCVD或急性冠心症相關條件，風險分級應以較高者（非常高/極高風險）為準，而非停留在CKD單獨對應的高風險層級——三個風險等級判斷準則（§3.1極高、§3.2非常高、§3.3高）彼此並非互斥列舉，臨床上應依§3.8流程圖由高風險至低風險依序檢核，符合任一較高等級條件即以該較高等級認定。
- 已進入透析治療之CKD病人，依表一「進入透析治療前的慢性腎臟病」定義文字，**不屬於本條CKD高風險認定範圍**——這類病人的風險分級判斷，需回歸是否符合其他極高/非常高/高風險準則（如是否合併確診ASCVD），本文提供之來源材料未見透析病人另有專屬分級規則，若臨床上不確定歸類方式，建議標記為待釐清事項而非自行假設。

#### （四）一般內科門診（一次性血脂異常評估、初診）

- 初診病人若無明確ASCVD病史、無糖尿病/CKD/LDL-C≥190/CAC≥400等高風險條件，應依§3.6逐項核算心血管風險因子個數（高血壓、年齡、早發性冠心病家族史、低HDL-C、抽菸、代謝性症候群，共6大類）以決定中風險（≥2項）或低風險（1項）或0項風險因子分級。
- 中/低風險病人的治療流程與極高/非常高/高風險病人**明顯不同**：起始治療為「生活型態改變＋處置心血管風險因子」（非立即用藥），需**3-6個月**後追蹤才考慮給予中強度statin，再6-8週後追蹤達標與否——一般內科門診排程規劃回診間隔時，應對照此較長的初始觀察期，避免對中/低風險病人過早起始藥物治療而與給付規定的治療流程不符。
- 一般內科在轉介判斷上：若門診發現嚴重高膽固醇血症、肌腱黃色瘤、早發心血管疾病或家族病史，即使目前僅落在高風險分級，仍**應依台灣家族性高膽固醇血症診斷標準進行篩檢**（可能需轉介心臟科/新陳代謝科/遺傳諮詢相關資源），不應僅以LDL-C數字表面達標與否作為唯一判斷依據。

### 6.2 常見病人情境之具體處方決策路徑

**情境1：糖尿病、無ASCVD病史、LDL-C 128 mg/dL、無CKD/CAC資料**
→ 依§3.3「糖尿病」條件，直接判定**高風險**（無需計算風險因子個數，糖尿病本身即為高風險認定條件之一）。
→ 目標LDL-C<100（non-HDL<130）。基礎值128<起始治療門檻(≧100)已超過，屬應起始治療族群。
→ 起始治療：中至高強度statin或合併ezetimibe，同時生活型態介入。
→ 6-8週後複查：達標則每6個月追蹤；未達標則升級高強度statin/最大耐受劑量，或合併ezetimibe/PCSK9單株抗體等non-statin治療。

**情境2：糖尿病＋確診ASCVD（如曾行PCI）**
→ 依§3.2「接受血管再通術」，判定至少**非常高風險**；若同時合併§3.1極高風險條件（如一年內MI、ACS合併糖尿病）則進一步升級為**極高風險**。
→ 目標LDL-C<70（或<55）。需特別注意：**"急性冠心症合併糖尿病"本身即列於§3.1極高風險判斷準則之一**，糖尿病病人若同時發生ACS，應直接以極高風險認定，而非僅以非常高風險處理。

**情境3：ACS剛發作（住院中）**
→ 入院24小時內完成完整血脂檢驗（§3.7強制要求）。
→ 依§3.1/§3.2判斷是否達極高或非常高風險（多數ACS病人至少屬非常高風險，若合併§3.1所列合併症則為極高風險）。
→ 起始治療：中至高強度statin或合併ezetimibe，同時處置可改善心血管風險因子（血壓、HbA1c、肥胖、抽菸、酒精攝取、生活型態）。
→ 出院前應確認後續6-8週血脂追蹤排程，並於病歷/出院準備服務中明確記載風險分級與治療目標值，供銜接門診之心臟科/家醫科團隊參考。

**情境4：慢性穩定CAD、長期服用中強度statin、近期LDL-C 78 mg/dL**
→ 依§3.2判定非常高風險，目標<70 mg/dL；現值78未達標。
→ 依處方規定第二步：檢視服藥狀況（遵從性、劑量是否已達最大耐受）；考慮調整至高強度statin或最大耐受statin劑量，同時考慮合併non-statin治療（ezetimibe為條文明列首選之一）。
→ 若加用ezetimibe/statin複方（FDC），須依§2.4查核所使用之特定複方健保代碼屬2.6.3之6-8週新制或3個月例外清單，據以決定病歷記載之前置治療期間佐證要求。

**情境5：CKD病人（eGFR 52 mL/min/1.73m²，已持續4個月），無ASCVD病史**
→ eGFR<60已持續逾3個月，依§3.3判定**高風險**。
→ 目標LDL-C<100（non-HDL<130）。
→ 起始治療與追蹤流程比照高風險族群（生活型態改變＋藥物治療並行，6-8週追蹤）。
→ 用藥選擇上，CKD病人之statin/ezetimibe選擇需另外考量腎功能相關劑量調整與安全性（屬safety-pharmacology領域之藥物安全性議題，非本次給付規定文件涵蓋範圍，建議另行參考藥品仿單與腎功能劑量調整指引，本文不代為建議劑量）。

**情境6：老年病人（>75歲）、多重共病、多重用藥**
→ 風險分級仍應依§3.1-3.6之臨床/檢驗準則判斷，年齡本身（男性≥45歲、女性≥55歲）僅為§3.6心血管風險因子計數中的一項，並非獨立的極高/非常高/高風險認定條件。
→ 老年病人常合併多重用藥（HTN、DM、CAD用藥等），起始或調整降血脂治療前，應併同考量藥物交互作用與整體治療負擔（屬safety-pharmacology-intelligence部門之DDI專責範疇，本文件不重複展開）。
→ 給付規定文件本身未見针對老年族群的獨立分級或門檻調整規定，若臨床上對高齡、極高齡病人之治療目標值有保留意見，建議與病人/家屬共同討論後於病歷載明個別化考量，而非逕自更動系統對應的表一分級（給付判定仍依§3.1-3.6之臨床/檢驗準則認定，不因年齡另設寬減）。

**情境7：Statin不耐受病人（如Severe myalgia/Myositis）**
→ 依§2.3（2.6.2條件1）：新制**已取消「須先符合2.6.1降血脂藥物給付規定表資格」之前置要求**，僅需符合原發性高膽固醇血症/HoFH/同型接合子性麥脂醇血症等診斷，並發生statin不耐受不良反應者，即可使用ezetimibe單方。
→ 選用ezetimibe單方藥品時，仍須依§4.8查核所選具體品項是否落在AC60610100/BC26552100/BC27311100/BC28252100此4個維持原給付規定代碼——**此4碼本身即屬「維持原給付規定」清單，其statin不耐受條件本身之判定邏輯（2.6.2條件1）並無6-8週/3個月的期程差異，該期程差異只出現在條件2（statin治療未達標後加用）**，故statin不耐受此一情境下，實務差異主要在於「是否仍需先符合2.6.1資格」之取消，而非期程長短問題，處方時仍建議留意品項代碼以利申報一致性。

### 6.3 門診開藥實際工作流程（7步驟，含實務細節與常見陷阱）

**Step 1：確認病人風險分級**
依§3.8流程圖，由極高風險往下逐級核對，取符合條件之最高等級。
> 陷阱：勿僅以「有沒有糖尿病」「有沒有心臟病」二分法判斷，必須逐條核對§3.1-3.3之具體臨床/影像/檢驗準則文字（如「≥50%直徑狹窄率」「UACR≥30mg/g」「CAC≥400」）。缺乏影像或檢驗數據時，不應假設病人達到某風險等級的門檻，應依現有客觀資料判定，缺漏部分於病歷載明「待進一步檢查」。

**Step 2：確認LDL-C起始治療門檻與目標值**
依§2.2表格核對該風險等級對應之起始治療門檻（如高風險LDL-C≧100）與目標值（<100，non-HDL<130）。
> 陷阱：起始治療門檻與治療目標值是兩組不同的數字（如高風險起始門檻100、目標同為100——但極高風險起始門檻55、目標亦為55；請勿與其他風險等級之起始/目標數字混淆抄寫，逐級核對§2.2原表為宜）。

**Step 3：選擇具體處方藥品，並查核其健保代碼所屬清單**
不論成分為何，**開立處方前務必以實際調劑品項之健保代碼**（而非成分名稱、廠牌名稱、甚或印象中「這家藥廠通常都有擴增」）對照§4完整表格，確認該代碼屬🟢擴增或⚪維持。
> 陷阱：同一醫師若同時處方多個廠牌/劑量的同成分藥品（如因缺藥調劑更換廠牌），每次調劑後應重新核對新品項代碼之給付狀態，不可比照前次處方之廠牌狀態直接延續認定。

**Step 4：若為ezetimibe單方或statin/ezetimibe複方，額外核對前置治療期間**
依§2.3/§2.4之例外代碼清單，確認該特定品項是否仍需3個月前置statin單方治療，或已適用6-8週新制。
> 陷阱：**前置治療期間的例外清單，與擴增/維持原給付清單，是兩份不同邏輯的清單，不可互相取代查詢**。一個品項即使列於「維持原給付規定（⚪）」清單，也不代表它一定同時列於「3個月例外」清單（例如需交叉核對§2.3/§2.4所列之特定代碼），必須分別查核。

**Step 5：起始治療後排定追蹤時間點，並於病歷載明依據之風險分級**
依§2.2各風險等級對應之追蹤週期（極高/非常高/高風險為6-8週；中/低風險為3-6個月），排定回診/複檢時間，並於病歷明確記載當次判定之ASCVD風險等級與所依據之§3臨床準則條文內容（例如「非常高風險，依據：急性冠心症病史」），作為未來申報佐證。

**Step 6：追蹤達標與否，據以決定維持或調整治療**
達標：維持治療，依風險等級排定下一次追蹤（極高/非常高/高風險每6個月；中/低風險每6-12個月）。
未達標：依§2.2各等級處方規定第二/三步驟調整（升級statin強度/劑量、或合併non-statin治療），並於調整治療後1-3個月內（極高/非常高/高風險）或依中/低風險規定之時程再次追蹤達標情形。
> 陷阱：「調整治療後1-3個月內追蹤」是一項**獨立於起始6-8週追蹤之外的第二個追蹤時間點**，門診排程系統若僅設定單一固定回診間隔，可能遺漏此二次追蹤要求，建議於病歷/提醒系統中明確標記「治療調整後複查」與「常規達標後追蹤」兩種不同性質的回診提醒。

**Step 7：病歷紀錄完整留存風險分級依據、藥品代碼、前置治療佐證**
每次異動治療（起始、升級、更換品項）時，病歷應同時載明：(a) 當次判定之ASCVD風險等級與依據之§3準則、(b) 處方藥品之具體品名與健保代碼、(c) 若涉及ezetimibe/複方，statin單方前置治療起訖時間與檢驗結果佐證（達6-8週或3個月門檻）。

### 6.4 病歷紀錄要點與核刪風險防範

1. **風險分級判斷依據務必具體到條文層級，避免僅寫「高風險」而不註明依據**。例如：宜寫「高風險（依據：糖尿病病史，診斷日期____，HbA1c____）」，而非僅寫「病人屬高風險」，以利事後審查對照§3.3條文逐項核實。
2. **CKD相關高風險認定，務必於病歷載明UACR或eGFR數值、檢驗日期，並確認「至少持續3個月」之時間條件已滿足**——單次檢驗異常不足以支持CKD高風險認定，需有連續/追蹤資料佐證持續性。
3. **影像學非常高風險認定（≥50%狹窄率）務必附具體影像報告數字與檢查日期**，而非僅憑臨床印象記載「有明顯斑塊」。
4. **statin/ezetimibe前置治療期間之佐證**：病歷應明確記載statin單方起始日期、劑量、期間內之血脂追蹤數值，以及是否達到6-8週或3個月門檻（依所選品項適用哪一組規定），供核刪審查時直接比對。
5. **表一/表二歸屬與藥品代碼之對應紀錄**：若處方品項為§4所列「維持原給付規定」清單中之藥品，病歷佐證仍應依循舊制邏輯記載（本文件因來源資料所限，未能提供舊制逐字條文，此部分建議另行取得108/2/1版本降血脂藥物給付規定表全文作為病歷紀錄與申報依據，避免僅憑新制表一邏輯記載舊制品項）。
6. **治療調整後之二次追蹤（1-3個月內）不可省略病歷記載**，即使結果與起始追蹤相同或病人狀況穩定，仍建議留下複查紀錄，以完整呈現符合處方規定三步驟流程之軌跡。

### 6.5 HIS／藥事系統落地建議

1. **健保代碼層級之給付狀態旗標**：建議於院內HIS/藥局系統之藥品主檔，針對本文§4所列187個健保代碼，逐一建立「表一（擴增）」/「表二（維持原給付）」旗標欄位，並於醫師開立處方、藥師核發時彈跳提示，避免人工查表延誤或疏漏（尤其同成分不同劑量分屬不同表之品項，如Crestor三劑型、Tonvasca vs LIVAZEBE HD）。
2. **ezetimibe/複方前置治療期間之例外代碼獨立標記**：§2.3、§2.4所列共14個「3個月例外」代碼，建議於系統中另立獨立欄位（不與擴增/維持欄位混用），因兩者邏輯不同、不可互相推論（見§6.3 Step 4陷阱說明）。
3. **風險分級輔助計算工具**：若院內系統具備結構化欄位（糖尿病診斷、CKD相關檢驗數值與持續時間、心血管風險因子逐項勾選），建議開發依§3.1-3.6準則之半自動風險分級試算功能，供醫師開立處方前參考，惟**最終風險分級判斷仍須由臨床醫師依病人實際狀況確認**，系統試算僅供輔助，不可取代臨床判斷逕自核刪或自動放行。
4. **追蹤時間點自動提醒**：依§2.2起始治療6-8週或3-6個月之首次追蹤時間點，以及未達標後1-3個月之二次追蹤時間點，建議於病歷/回診排程系統設定自動提醒，避免因排程間隔固定（如常規3個月）而錯過條文所定之特定追蹤週期。
5. **申報比對前之代碼異常檢核**：本文§4.5、§4.6標記之「A055967100」「A042389100」兩個疑似繕打異常代碼，若院內系統採用來源檔案原始代碼進行比對，建議先與健保署最新官方版清單核對正確性，避免因代碼格式異常導致系統比對失敗或誤判。

## 7. 常見誤解 QA

**Q1：同一成分（如atorvastatin）是不是全部品項都適用新制表一？**
**A：不是。** 這是本次新制最容易誤解之處。給付狀態是以**個別健保代碼**（醫令代碼）認定，而非以成分或藥品名稱認定。例如atorvastatin共36項品項中，僅11項擴增、25項維持原給付（詳見§4.1完整表格）；即使同一品牌，不同劑量也可能分屬不同表（如Crestor 10mg擴增、5mg/20mg維持，見§4.2）。**開立處方前務必查核實際調劑品項之健保代碼。**

**Q2：舊制病人（9/1前已在服藥、原本依舊表給付）是否需要重新評估風險分級？**
**A：本文件現有來源材料未明確說明過渡期／既有病人之銜接規定**，附件2、附件1與兩份藥品清單均未觸及「已在治療中病人是否需於9/1後重新以表一評估」此一行政過渡問題。建議此問題標記為待確認事項（NEEDS_ANALYST/NEEDS_PI），向健保署或轄區健保分區業務組另行確認，勿自行假設現行病人可沿用舊制邏輯或必須立即重新評估。

**Q3：換藥後（如從維持原給付品項換成擴增品項），給付規定是否跟著改變？**
**A：是的，給付規定跟隨「目前實際處方之健保代碼」而定，不是跟隨病人或跟隨成分。** 若病人原服用維持原給付規定之atorvastatin品項，之後換成擴增清單中的atorvastatin品項，該病人自換藥當次處方起，即適用新制表一之風險分級與目標導向邏輯；反之亦然。§5.2之Tonvasca→LIVAZEBE HD劑量調整範例即為此類換藥情境的具體案例。

**Q4：Ezetimibe單方前置statin治療期間，是不是所有ezetimibe藥品都已經縮短為6-8週？**
**A：不是全部。** 新制原則上將前置期間由3個月縮短為6-8週，但§2.3列出的4個特定健保代碼（AC60610100、BC27311100、BC28252100、BC26552100）**仍維持3個月**，未享有縮短。這4個代碼恰好也是ezetimibe單方「維持原給付規定」清單中的品項，但需注意「維持原給付規定清單」與「3個月前置期例外清單」是兩份不同邏輯的清單，不可直接互相推論等同（詳見§6.3 Step 4陷阱說明）。

**Q5：Statin/ezetimibe複方（FDC）藥品的前置statin治療期間，是否也一律縮短為6-8週？**
**A：同樣不是全部。** §2.4列出10個特定健保代碼仍維持3個月，其餘複方品項則適用6-8週新制。Tonvasca（AC61165100）**不在**這10個例外代碼之中，故推論其適用6-8週（詳見§5.1說明其推論性質）；但LIVAZEBE HD（BC28884100）**明確列於**此例外清單，仍須3個月。

**Q6：Statin不耐受病人使用ezetimibe單方，是否也受6-8週/3個月前置期間規定限制？**
**A：不受此限制，這是另一項條件。** §2.3條件1（statin不耐受）與條件2（statin單方治療未達標後加用）是**兩個獨立的適用情境**，6-8週/3個月的前置治療期間規定僅適用於條件2（statin治療失敗後加用ezetimibe），不適用於因不耐受而無法持續statin治療、改用ezetimibe單方的情境。新制條件1的主要變化是**取消「需先符合2.6.1降血脂藥物給付規定表資格」的前置要求**，而非期程長短的變化（詳見§6.2情境7）。

**Q7：原廠藥是不是都比較容易列入擴增名單？**
**A：沒有一致規律，不能一概而論。** 依§4.15統計整理之型態觀察：Crestor 10mg（原廠rosuvastatin）擴增；但LIVALO（原廠pitavastatin，力清之，兩劑型）全數維持原給付；EZETROL（原廠ezetimibe，怡妥）、ATOZET（原廠atorvastatin/ezetimibe複方，優泰脂）、VYTORIN（原廠simvastatin/ezetimibe複方，維妥力）皆列入擴增。原廠/學名藥身分本身不是判斷依據，仍須以個別健保代碼查核。

**Q8：Rosuvastatin+ezetimibe複方（如Cretrol）是不是這次也有放寬給付？**
**A：沒有。** Cretrol兩個劑型（10/10mg、10/20mg，健保代碼BC28181100、BC28182100）**皆列於維持原給付規定清單**，且同時也列在2.6.3的3個月前置期間例外清單中——換言之，rosuvastatin+ezetimibe這個成分組合，在本次新制中**完全未獲得任何放寬**（無論是表一目標導向給付、或是6-8週前置期間縮短），是唯一「複方類別0%擴增」的品項組合（詳見§4.12、§4.15）。若簡報或文章欲以本次新制作為rosuvastatin+ezetimibe臨床定位論點，須特別注意此點，避免誤植。
